# Product spec — Aayam demo

## Purpose
Help students and early-career learners reflect on interests, explore career possibilities, identify areas to learn, and collect evidence of progress.

## Users
The profile wizard adapts its study prompt for school, college, and graduate/early-career stages. Personal information is optional and limited to a display name, study context, interests, goal prompt, and available learning time.

## Current experience
Landing page → profile → informal reflection → career discovery/details → skill exploration → roadmap → portfolio → dashboard. Career selection informs the skill list and roadmap; completion state updates the dashboard; portfolio evidence can appear in the skill view.

## Boundaries
This is a local frontend demo. Assessment output is a reflection of selected answers, not a standardized psychometric instrument. Career information is illustrative, not authoritative or live. It makes no employment, income, or outcome claims.
