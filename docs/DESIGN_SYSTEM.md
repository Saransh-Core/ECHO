# Design system

- Background: warm ivory `#F8F7F2`; surfaces white; text `#202A39`; navy `#172B4D`.
- Growth accent: sage `#789780` and dark sage `#426B57`; restrained blue is used for selection and exploration states.
- Display type: Manrope. Interface/body type: DM Sans with system fallbacks.
- Spacing follows compact 4px multiples. Cards use subtle 1px borders and 11–13px corners; controls have visible focus rings.
- Desktop workspace uses a persistent left navigation; mobile uses a slide-in navigation with a scrim. Responsive layouts reflow cards and forms rather than shrinking a desktop canvas.
- Motion is restrained and disabled under `prefers-reduced-motion`.
